# REQUIREMENTS TRACEABILITY MATRIX (RTM)
## Specialized Blockchain Cyber-Fraud Investigation Engine for Indian Law Enforcement (CryptoTrace-Sentinel)
**Standard:** IEEE 830 / ISO/IEC/IEEE 29148 Traceability Standard  
**Statutory Framework:** Section 94, Bharatiya Nagarik Suraksha Sanhita, 2023 (BNSS) & Section 63, Bharatiya Sakshya Adhiniyam, 2023 (BSA)  
**Target Agency:** Ministry of Home Affairs (MHA) / Indian Cybercrime Coordination Centre (I4C) / State Police Cyber Cells  

---

### Matrix Legend
- **Req ID**: Specification section identifier (Sections 1 through 74)
- **Frontend Component**: React/Vite UI modules implementing the view or interaction
- **Backend Service**: Python/C backend module implementing business logic
- **Algorithm / Heuristic**: Mathematical, graph, or forensic algorithm applied
- **Database Entity**: SQLite / PostgreSQL relational schema table
- **API Endpoint**: OpenAPI REST route
- **Test File**: Automated regression verification suite
- **Demo Scenario**: Interactive simulation verifying the capability
- **Documentation**: Referenced methodology and design documentation
